# Catálogo MCP
Servidores MCP conocidos que Prometeo puede recomendar (nombre — para qué sirve en un proyecto):
- GitHub — repositorios, issues y pull requests; la IA puede leer el código y gestionar tareas del repo.
- GitLab — lo mismo que GitHub para equipos en GitLab.
- Linear / Jira — gestión de tareas y sprints; convertir tareas.md en tickets.
- Notion — documentación, wikis y bases de datos de equipo.
- Obsidian (sistema de archivos) — notas locales y vaults de documentación.
- Google Drive / Google Docs — documentos y hojas compartidas.
- Slack — comunicación del equipo, avisos y resúmenes de canales.
- Figma — leer diseños, componentes y design tokens para implementar interfaces.
- Postgres / Supabase / SQLite — consultar y diseñar la base de datos.
- Stripe — pagos y suscripciones.
- Sentry — errores y rendimiento en producción.
- Vercel / Cloudflare — despliegue y hosting web.
- Playwright / navegador (Chrome) — probar webs, automatizar navegación, capturas.
- Context7 — documentación actualizada de librerías y frameworks para programar.
- Brave Search / búsqueda web — investigación y datos actuales.
- Google Calendar — fechas, hitos y reuniones del plan.
- Filesystem — leer y escribir archivos locales de un proyecto.
